With all of my recent board-gaming activity, my shelves have been shuffled and sorted and scrambled,
and I'd like to do another audit to make sure I know where everything is.
Of course I don't rush into these sorts of chores, so while I was thinking about it I had the idea that I could use the Extstats tagging system to help me.
I hit upon the idea of using locations as tags, and tagging each game with one of those locations.

<Image src={audit1} alt="Tagging setup for an audit" width={854} /><br/>
<caption>S1 is shelf 1, SB/3 means on the shelf between the book case and shelf 3, etc.</caption>
<p/>

So the plan is give each game one of these tags.
Then I realised I really needed to know which games had not been found in the audit - that speeds up the location of games in my lists.
So I created a "taggroup" selector which returns all games tagged with a tag from the nominated tag group.
I can then use the Catalist to compose a query for games which have not been found in the audit.

<Image src={audit3} alt="A query for finding which games have not been located" width={854} /><br/>
<caption>This will give me all the games without any of those tags</caption>
<p/>

If I run that query in a new window, I get a page where I can just click on a tag when I find a game.

<Image src={audit4} alt="The page for filling in where all the games are" width={854} /><br/>
<caption>It clicks on one tag per game or it gets the hose again</caption>
<p/>
